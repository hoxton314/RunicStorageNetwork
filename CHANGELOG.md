# История изменений

## 0.8.1

- Исправлена установка Кодекса запасов: модель предпросмотра пропадала, а постамент строился высоко над землёй, из-за чего не было слышно звука строительства.

## 0.8.0

- Добавлен «Рунный кодекс»: создаётся на кузнице из серебра, кристаллов, глаз грейдворфа, льняной нити и обрывков кожи.
- Добавлен «Кодекс запасов» — постамент с книгой для поиска и получения предметов из подключённых хранилищ. Строится молотком из Рунного кодекса, качественной древесины, камня, железа и красного джута.
- Окно хранилища перенесено с ядра на Кодекс запасов. Для работы разместите его в зоне снабжения ядра или подключённого реле.
- Взаимодействие с ядром теперь открывает переименование сети.

## 0.7.5

- Обновлены иконки ядра и реле: направленный свет и более мягкие блики лучше подчёркивают форму построек.
- Иконка мода обновлена вместе с иконкой ядра.

## 0.7.4

- Исправлено обрезание рамок крайних ячеек в хранилище сети.

## 0.7.3

- Белая заливка ячеек в хранилище сети заменена на лёгкий полупрозрачный фон с тонкими рамками.
- Окно переименования сети на ядре оформлено в одном стиле с хранилищем.

## 0.7.2

- Окно хранилища сети получило тёмный фон, сетку предметов и компактную панель выдачи.
- При наведении на ресурс показываются название и описание. Качество предметов отмечено в сетке.
- Обновление запасов сохраняет выбор предмета и по возможности положение просматриваемого ресурса.

## 0.7.1

- Исправлена ошибка, из-за которой окно хранилища сети не открывалось при взаимодействии с ядром.

## 0.7.0

- На ядре добавлено окно хранилища сети с поиском, количеством ресурсов и выбором количества для получения.
- Ресурсы из подключённых хранилищ можно забирать прямо в инвентарь.
- Предметы разного качества отображаются отдельно. Полученные предметы сохраняют свои свойства.
- Обычное взаимодействие с ядром открывает хранилище; дополнительное взаимодействие позволяет переименовать сеть.

## 0.6.0

- Ускорена работа меню крафта в больших сетях: обновляются изменившиеся хранилища вместо постоянного пересчёта всех сундуков.
- Просмотр рецептов больше не резервирует материалы и не удерживает хранилища для крафта. Резерв создаётся после нажатия кнопки крафта.
- При выборе рецепта обновляются его ингредиенты, включая ресурсы, добавленные в ранее пустые хранилища.
- Исправлено исчезновение ингредиентов из меню крафта при задержке ответа или временной недоступности хранилища.
- Подтверждённые материалы остаются доступными во время анимации крафта при фоновом обновлении количества ресурсов.
- Устаревшие ответы хранилищ больше не заменяют более свежие сведения о ресурсах.
- Сокращены повторные проверки рецептов с сохранением поддержки их изменения во время игры.

## 0.5.6

- Исправлен выбор неправильного рецепта при сетевом крафте, когда моды назначают нескольким рецептам одинаковое внутреннее имя.
- Сетевой крафт теперь учитывает рецепты, добавленные, включённые или изменённые во время игры.
- После изменения рецепта больше не используются резервации ресурсов, подготовленные для его прежних требований.
- Добавлены понятные сообщения в журнале, когда не удаётся сопоставить рецепт у разных игроков.
- Поднос теперь может использовать еду из подключённых хранилищ для подачи.
- Строительство берёт ресурсы из сети инструментами из других модов, а не только ванильным молотом.
- Добавлен раздел конфигурации `Building` для выбора строительных инструментов, работающих с сетью. Изменения применяются без перезапуска игры, а в совместной игре состав определяет сервер.
- Строительство при достаточном количестве материалов в инвентаре больше не зависит от доступности сети.

Спасибо [hoxton314](https://github.com/hoxton314) за поддержку дополнительных строительных инструментов в [PR #2](https://github.com/rerit33/RunicStorageNetwork/pull/2).
Спасибо [hoxton314](https://github.com/hoxton314) за единый поиск рецептов в [PR #3](https://github.com/rerit33/RunicStorageNetwork/pull/3).

## 0.5.5

- Добавлено необязательное название сети: его можно задать на ядре или очистить, чтобы оставить сеть безымянной.
- В подсказке подключённых хранилищ теперь отображается подключение к сети и её название, если оно задано.
- Исправлено игнорирование трофеев и других ингредиентов рецептов в подключённых хранилищах.
- Предметы с уровнями улучшения или дополнительными данными модов теперь можно использовать из хранилищ, если они требуются рецептом.

## 0.5.4

- Добавлено автоматическое подключение подходящих стационарных хранилищ из других модов.
- Добавлены серверные настройки разрешённых и исключённых типов хранилищ с применением без перезапуска игры.
- В диагностику добавлена информация о поддерживаемых и исключённых типах хранилищ.

Спасибо [hoxton314](https://github.com/hoxton314) за вклад: поддержку модовых хранилищ, настраиваемые правила подключения и диагностику в [PR #1](https://github.com/rerit33/RunicStorageNetwork/pull/1).

## 0.5.3

- Добавлен статус подключения при установке. Реле без связи по-прежнему можно поставить и подключить позже.
- Совпадающие круги подключения хранилищ и снабжения объединены, при установке показаны подписи радиусов.
- Убрано количество переходов до ядра из подсказки реле. В счётчиках используется слово «хранилища», учитывающее и бочки.
- В README добавлены несовместимые моды, требования к версиям интеграций и ссылки на заявки об ошибках на GitHub.

## 0.5.2

- Исправлено временное исчезновение ресурсов из обзора при резервировании сундука или блокировке его ячеек в MultiUserChest.
