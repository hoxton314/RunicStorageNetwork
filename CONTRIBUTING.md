# Bug reports / Сообщения об ошибках

## English

Open [a new issue](https://github.com/rerit33/RunicStorageNetwork/issues/new/choose) and select the English bug report form. Feature suggestions and other questions can use a blank issue.

Include the mod and game versions, steps to reproduce, expected and actual results, and whether you play solo, host a session or use a dedicated server. For multiplayer problems, include versions and logs from the affected players and the host/server when possible.

Attach logs soon after the problem occurs, before another game session replaces them:

- `Player.log`: `%USERPROFILE%\AppData\LocalLow\IronGate\Valheim\Player.log`
- `LogOutput.log`: the active profile's `BepInEx` folder (or the game's `BepInEx` folder for a manual installation).

Include the approximate time of the problem and the affected recipe or building. A mod list or profile code and screenshots are useful. Check logs for personal information, server addresses and passwords before posting them publicly.

If you have already tested with only Runic Storage Network, BepInEx and Jötunn, mention the result. This is helpful but not required to submit a report.

For code changes and local tests, see [BUILDING.md](BUILDING.md). Keep changes focused and explain the player-visible problem they solve. Write changelog entries in plain language and describe only what changed.

## Русский

Откройте [новую заявку](https://github.com/rerit33/RunicStorageNetwork/issues/new/choose) и выберите русскую форму сообщения об ошибке. Для предложений и других вопросов можно создать обычную заявку без шаблона.

Укажите версии мода и игры, шаги воспроизведения, ожидаемый и фактический результат, а также режим игры: одиночный, совместная игра или выделенный сервер. Для сетевых ошибок по возможности приложите версии и логи затронутых игроков и хоста/сервера.

Сохраните логи вскоре после ошибки, пока следующий запуск игры их не заменил:

- `Player.log`: `%USERPROFILE%\AppData\LocalLow\IronGate\Valheim\Player.log`
- `LogOutput.log`: папка `BepInEx` активного профиля или папка `BepInEx` игры при ручной установке.

Укажите примерное время ошибки и название рецепта или постройки. Также помогут список модов или код профиля и скриншоты. Перед публикацией проверьте логи на личные данные, адреса серверов и пароли.

Если вы уже проверяли проблему только с Runic Storage Network, BepInEx и Jötunn, сообщите результат. Такая проверка полезна, но не обязательна для отправки заявки.

Инструкция по сборке и локальным тестам: [BUILDING.md](BUILDING.md). В изменениях кода описывайте, какую проблему игрока они решают. В changelog включайте только сами изменения простым языком.
